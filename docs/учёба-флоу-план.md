## 1. Суть раздела

«Учёба» — слой интервальных повторений (SRS) поверх всех слов пользователя
(словарь + докинутые из «Базы»). Цель: довести слова до устойчивого удержания,
а не «просмотреть один раз».

- Слово «живёт» через статусы: `new → learning → review → mastered` (+ `weak`, `archived`).
- **«Выучено» (mastered) = готово к экзамену** = пройдена вся **рампа сложности** (4 клетки),
  по **1 верному в каждой**:

  | # | Клетка | Что тренирует |
  |---|---|---|
  | 0 | **Карточка** (пассив) | знакомство, в зачёт не идёт |
  | 1 | **Выбор · норв→родной** | узнавание смысла |
  | 2 | **Выбор · родной→норв** | узнавание формы |
  | 3 | **Собери из букв · родной→норв** | правописание (продукция со страховкой) |
  | 4 | **Перевод · родной→норв** | полная продукция |

  Рампа «узнавание → сборка → ввод», всё ведёт к **производству норвежского**. «Печатать
  родной перевод» (input норв→родной) убрано как малоценное (узнавание смысла даёт клетка 1).
  Карточки (study) — пассивны. 🟡 *(меняет текущую реализацию — см. §4)*
- **Режим/направление не выбирает игрок** — система даёт следующую невыполненную ступень
  рампы для слова. 🟡
- Сила/интервал слова считаются по скользящему окну ответов; SRS сам возвращает слово
  перед тем, как ты его забудешь. ✅

## 2. Полный путь пользователя

### 2.1. Первый заход ✅
1. Открывает «Учёбу» → **онбординг** (полноэкранный, 1 раз): откуда слова, что значит
   «выучено», как работают интервалы. ✅
2. Дальше — **калибровка уровня** (если ещё не откалиброван).

### 2.2. Калибровка ✅
Три пути:
- **Входной тест** (адаптивный, ~3 мин) → уровень CEFR.
- **Самооценка** (выбрал уровень сам).
- **Пропустить** (калибровка в фоне).

После теста/самооценки бэкенд **досыпает стартовый набор ~20 слов** под уровень,
чтобы Учёба не была пустой. ✅

### 2.3. Ежедневная петля обучения ✅
- Вкладка **«Сегодня»**: герой **«К повторению»** (Smart Review) собирает сессию из
  `просроченные + слабые + новые`. ✅
- Альтернативы: н

аборы «Новые / Слабые / На повторении», быстрый запуск игры
  (Выбор / Перевод / Карточки). ✅
- Сессия — **один режим за раз**, переиспользует компоненты игр. ✅
- После сессии — **итог «что дальше»**: точность, серия, сколько осталось,
  «Ещё сессия» / «В Учёбу». ✅
- Дневная цель + стрик. ✅

### 2.4. Экзамены 🟡
**Главная новая механика. Сейчас НЕ реализована — спроектирована.**

У экзамена **две разные роли** (один экран «Экзамен», разные поводы):

#### A. Зачётный экзамен пачки — ВОРОТА К НОВЫМ СЛОВАМ
- **Источник:** текущая зреющая пачка (свежие `mastered`, ещё не сертифицированные).
- **Триггер:** по количеству — набралось ~100.
- **Зачем:** открыть приток новых слов.
- **Порог:** случайные **30 из 100**, сдать **≥25/30** (~83%).
- **Сдал** → сотня «сертифицирована», новые слова снова открыты, копится следующая пачка.
- **Не сдал** → промахи **демоутятся** `mastered → review`, возвращаются в «Сегодня».
  Пачка падает ниже 100.
- **Доучивание** = заново довести выпавшие до `mastered` (тем же механизмом 2/2).
- **Пересдача** открывается, когда пачка снова набрала **100 mastered** (= доучил все промахи,
  т.к. новые на время гейта не добавляются). Выборка — **новая случайная 30**.

Принципы:
- Гейт **мягкий**: блокируется **только приток новых**; повторения/слабые продолжают идти.
- **Без наказания** за провал (нет кулдаунов): доучи промахи → пересдай.
- Для замера берём **строго `mastered`**.
- **Первый чекпоинт раньше** (≈30–50), дальше каждые ~100.

#### B. Аудит-экзамен — ЛОВИТ ЗАБЫВАНИЕ СТАРОГО
- **Источник:** сертифицированные слова (ушедшие из ежедневной ротации).
- **Триггер:** по времени — у слова подошёл длинный «срок техобслуживания».
- **Выборка — по риску забывания, НЕ все и НЕ случайно:** берём N самых «просроченных»
  (дольше всех не проверялись / слабее), с **ротацией** (давнее всех → первым) и
  **потолком на сессию** (≈20–30). Со временем по кругу обходятся все слова, но за раз — чуть-чуть.
- **Итог пословно:** вспомнил → следующий аудит **ещё дальше** (срок растёт); забыл →
  **де-сертификация** и слово идёт **заново в очередь изучения**.
- **Мягче ворот:** провал аудита **не блокирует** новые слова.

**Петля забывания (зафиксирована, вариант A):**
```
аудит: забыл слово
  → в очередь «Сегодня» (learning/weak, приоритетно)   ← только забытые пословно, не вся сотня
  → доучил до mastered (2/2)
  → ре-сертифицирован сразу → назад под редкий аудит   ← без повторного прохождения ворот сотни
```
Возвращаем **только реально забытые** слова (промахи аудита), не весь пакет — остальные той
сотни проверит ротация аудита позже. Дневной бюджет не даст завалить очередь, даже если
вернулось много.

По сути аудит = **очень медленный SRS для сертифицированных слов**, но редкий и с лимитом,
поэтому ежедневная нагрузка не растёт (см. §2.6).

### 2.5. Переход уровня ✅ (связь с экзаменом — РЕШЕНО: независимы)
- Уровень закрывается, когда `mastered ≥ target` уровня (A1=250, A2=500, …). ✅
- При переходе — **празднование «Уровень X открыт»** (конфетти). ✅
- **Экзамен-ворота и уровни — независимы (вариант A):** ворота каждые ~100 пейсят новые слова,
  уровень закрывается сам по `target` и празднуется. **Отдельного «экзамена уровня» нет** —
  слова уже проверены воротами по дороге. Внутри одного уровня ворота срабатывают 2–3 раза.

### 2.6. Лимит нагрузки (чтобы повторений не становилось всё больше) 🟡
Проблема классического SRS: дневная пачка растёт вместе со словарём («review debt»).
Решаем тремя рычагами:
1. **Дневной бюджет повторений** — потолок на сессию (≈20–40), приоритет: просроченные → слабые → новые.
2. **Гейт на новые слова** (зачётный экзамен, §2.4-A) — нельзя влить много новых разом,
   зреющая пачка ограничена ~100.
3. **Выпуск по сертификации** — сданные на экзамене слова **уходят из ежедневной ротации**;
   их забывание ловит **аудит** (§2.4-B), а не ежедневный SRS.

**Важно:** дневного лимита практики НЕТ — хочешь учить больше, жми «Ещё сессия». Нагрузку
бьёт не будильник, а **лимит слов одновременно-в-работе** (new+learning ≈20): новые
подсыпаются по мере того, как закрываешь текущие до mastered. Так review-debt не копится,
но мотивированного не тормозим. Размер пачки-сессии (≈20) — лишь ритм по умолчанию.

Итог: **ежедневная нагрузка остаётся примерно постоянной** (≈10–15 мин) независимо от того,
сколько тысяч слов выучено. В daily-ротации крутится только зреющая пачка + редкие
возвраты из экзаменов; старое проверяется дёшево и редко аудитом.

## 6. Решено (зафиксировано)

- **Mastery = рампа из 4 клеток**: `Выбор норв→родной → Выбор родной→норв → Собери из букв
  родной→норв → Перевод родной→норв`, по 1 верному в каждой. Карточка — пассивный шаг 0.
  Убрано «печатать родной перевод». *(меняет текущий код — §4.2)*
- **Новый режим «Собери из букв»** (продукция со страховкой) — полноценная ступень рампы.
- **Направление** не выбирает игрок; система даёт следующую ступень. Вопрос направления закрыт.
- **Провал ворот:** демоут = **×2 промаха** (промахи + столько же самых слабых пачки).
- **Зачётный экзамен нейтрален** к интервалам; ошибки → в повторение.
- **Аудио-режима нет** — TTS озвучивает слово прямо в заданиях; «Аудирование» убрать и из экзамена.
- **Счётчики прогресса:** до открытия экзамена («выучить ещё N», X/порог) и до пересдачи
  («доучить N»). Лишние при штрафе — самые слабые по силе.
- Игры переиспользуются (рефактор на пропсы), один режим на сессию, 3 режима.
- Игры кормят SRS.
- Снисходительная диакритика при вводе.
- Экзамен = контрольный замер выученных, **ворота к новым словам** (механика 2.4-A).
- Доучивание = вернуть промахи в `mastered`; пересдача — когда пачка снова 100 `mastered`,
  выборка новая.
- Гейт мягкий (блок только новых), без наказания за провал.
- **Два типа экзамена**: зачётный (ворота, по количеству, текущая пачка) и
  аудит (на забывание, по времени, старые сертифицированные). Один экран — разные поводы.
- **Аудит = capped maintenance-выборка по риску забывания** (N самых просроченных, ротация,
  потолок на сессию) — НЕ все и НЕ случайно. Вспомнил → срок дальше; забыл → де-сертификация → в повторение.
- **Экзамен-ворота и уровни — независимы** (вариант A): ворота пейсят новые слова,
  уровень закрывается по `target` и празднуется; отдельного экзамена уровня нет.
- **Числа ворот:** первый чекпоинт **50**, дальше пачка **100**, выборка **30**,
  порог сдачи **27/30**. При провале — **заморозка** пачки. Добровольного экзамена нет.
- **Числа аудита:** первый аудит через **30 дней** после сертификации (дальше растёт),
  потолок сессии **~20**, мягкий тормоз новых при **>40%** забытого.
- **Сессии ведёт система, выбора режима НЕТ.** Один вход «Заниматься» → система сама
  собирает программу: какие слова и какую клетку (тип×направление) показать. «Сейчас это,
  в следующий раз то» — система раскладывает клетки по сессиям, покрывая все 4 со временем.
  Пользователь не выбирает Выбор/Перевод/направление. *(меняет текущий UI — §4)*
- **Лимит нагрузки** без дневного потолка практики: пейс новых = **лимит одновременно-в-работе
  ≈20** (слот освобождается по мастери), + гейт новых (ворота 100) + выпуск сертифицированных
  из daily-ротации (их держит аудит). Размер пачки-сессии ≈20 — только ритм, не стена.
- **Провал аудита (вариант A):** забытые слова **пословно** → заново в очередь изучения
  (приоритетно) → доучил до `mastered` → **сразу ре-сертифицирован** (без повторных ворот) →
  назад под редкий аудит. Не откатываем уровень, не блокируем повторения, без кулдаунов.

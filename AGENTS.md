# AGENTS.md

Инструкции для ИИ-агентов и разработчиков по этому репозиторию (фронтенд Lære Norsk).
Кратко: React 18 + Vite SPA, состояние на Zustand, запросы через `ky` к FastAPI-бэкенду
на Fly.io. Обзор и запуск — в [README.md](README.md).

## Команды

```bash
npm run dev      # дев-сервер (Vite, --host); ходит на ПРОД-бэкенд (см. .env.development)
npm run build    # обязательно проверять перед коммитом
npm run lint     # ESLint (--max-warnings 0)
```

Тестов нет — проверяй изменения сборкой (`npm run build`) и, по возможности,
вручную в браузере (дев-сервер общается с реальным бэкендом).

## Архитектура

- **Роутинг** — хэш-роуты в `src/App.jsx` (`#/words`, `#/pool`, `#/game`, `#/mypage`,
  `#/stats` — только админ, `#/authorization`, `#/registration`).
- **Состояние** — Zustand-сторы в `src/store/`:
  - `wordStore.jsx` — словари и пул; данные **серверные**, локально только текущая
    сессия (без persist). Мутации идут через методы стора, которые дёргают API и
    затем `loadData(true)` для тихого обновления. Эфемерное клиентское состояние
    (выбор слов для игры, выделение) — через `produce` (immer).
  - `systemStore.jsx` — язык интерфейса, тема.
  - `AuthStore.jsx` — пользователь, вход/выход.
- **API** — единый класс `ApiService` в `src/components/tools/api.js` (`ky`):
  все запросы тут, автоматический refresh JWT, токены шифруются (`crypto-js`).
  Новые эндпоинты добавляй сюда методом, не вызывай `ky`/`fetch` из компонентов.
- **Бэкенд** — отдельный репозиторий `laereNorskBackand` (FastAPI, Fly.io). Если
  задача требует нового эндпоинта/поведения сервера — менять надо там.

## Конвенции

- **Комментарии и UI-тексты — на русском** (как в существующем коде). Комментируй
  «зачем», а не «что».
- **Стиль кода** — повторяй окружающий: функциональные компоненты, хуки, селекторы
  Zustand (`useWordsStore((s) => s.x)`), без классов. Отступы 4 пробела.
- **i18n — обязательно**: любая новая строка интерфейса добавляется во **все 5
  языков** в `src/interface/interfaceTranslation.jsx` (ru, ukr, en, pl, lt). Доступ
  через `const t = interfaceTranslate[currentLanguage]`.
- **Иконки** — только из спрайта `src/styles/icons.js`, рендер `<Icon n="имя" sm />`.
  Новую иконку сначала добавь как `<symbol id="i-имя">` в спрайт.
- **Стили** — CSS-классы в `src/styles/` (`app.css`, `screens.css`, `components.css`).
  Инлайн-стили допустимы для мелочей; крупное — классами. Дизайн-токены через
  CSS-переменные (`var(--sp-4)`, `var(--game-accent)` …).
- **Модалки** — общий `components/ui/Modal.jsx` (+ `WordInfoModal.jsx` для слов).

## Важные нюансы

- **Два lock-файла**: есть и `yarn.lock`, и `package-lock.json`. **Vercel собирает
  через yarn** → при добавлении зависимости убедись, что она попала в `yarn.lock`
  (иначе прод-сборка упадёт на frozen-lockfile), и закоммить оба lock-файла.
- **Описания/синонимы** слов генерируются бэкендом по запросу при открытии карточки
  и кешируются; фронт показывает скелетон во время загрузки.
- **Языки переносов** (`src/components/ui/hyphenate.js`): норвежский — `nb`,
  украинский — `uk` (не `ukr`!), остальные совпадают с ключами интерфейса.
- **Мобильность**: игровые экраны должны влезать в один экран телефона без скролла
  (`.play` = 100dvh, `.pstage` гибкий; см. `screens.css`). Длинные слова переносятся
  (`hyphenate` + `overflow-wrap`).

## Деплой

- **Фронт**: коммит → пуш в `master` → авто-деплой Vercel. Коммить/пушить только по
  явной просьбе пользователя.
- **Бэк**: репозиторий `laereNorskBackand`, `flyctl deploy` (app `learn-norsk-backend`).
